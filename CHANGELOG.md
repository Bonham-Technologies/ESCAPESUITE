# Changelog

Notable changes to ESCAPE Suite, newest first. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/). Each app's release notes are in its own
`CHANGELOG.md` under `apps/`, written by Changesets when a version ships.

## Unreleased

- Hosted site: every hub page in sitemap.xml now carries the date it last changed, also on the live site, where the dates had been missing because the hosting builds from a shallow copy of the history; the dates come from a file kept in the repository, and a test fails when a page changes without its date (ESCSUITE-490).
- ESCAPEARTIST: WebM and GIF exports, and in-page MP4 exports of videos imported in Chrome or Edge, of a slowed clip (0.25× or about 0.4×, especially of a 50, 60 or 120 fps video) no longer show the frame before in place of some of its frames: the exporter now moves to each new frame of the video, judged at the video's own frame rate, instead of staying put whenever the next request is within part of an output frame; the headless render kit too (ESCSUITE-505).
- Tests: an e2e spec imports Firefox and Chromium MediaRecorder recordings of known colours into ESCAPEARTIST and checks that the seek index the import adds changes no colour in the preview, in either browser; it measured none, and found that Firefox's MediaRecorder records no VP9 (ESCSUITE-504).
- ESCAPEARTIST: the export dialog's "close a couple of seconds after finishing" timer is cancelled when the dialog goes away or a new export starts, so it can no longer close the dialog after the fact, and the unit suite no longer fails now and then with an error after every test has passed (ESCSUITE-502).
- ESCAPEARTIST: cancelling a WebM export that is saving to a slow picked file no longer leaves a "Cannot write to a closing writable stream" error in the browser console (the cancel itself already worked), and an MP4 or WebM export with a frame or a stretch of sound the video file refuses to take now stops and shows the reason, instead of finishing as if all was well with that part missing from the file; the headless render kit too (ESCSUITE-499).
- ESCAPEARTIST: in Chrome and Edge, a project with a clip whose media is no longer stored in this browser can be saved again: the first Save and Save Project As write the new file without that media and name it in a notice, as the download always did, while a Save over the project's existing file still refuses before it asks for anything, so it no longer leaves an empty file behind; that refusal points you to a copy under a different name, and Save Project As then suggests the project's name plus " copy" (ESCSUITE-497).
- ESCAPEARTIST: in Chrome and Edge, where the export dialog's buttons open a save dialog and write to the file you choose, they now read "Export WebM…", "Export MP4…" and "Export GIF…" instead of "Download …", for screen readers too; browsers that download the export keep "Download …" (ESCSUITE-498).
- ESCAPEARTIST: Zoom to region and Crop on canvas close when you select another clip or deselect, so selecting the first clip again shows them closed instead of reopening the box and the form by themselves; selecting the same clip again keeps them open (ESCSUITE-500).
- Tests: the e2e WebM reader now also reads frames stored in BlockGroups, where Mediabunny puts the last frame of each Cluster, so specs that count or check an ESCAPEARTIST export's or ESCAPECRAFT take's frames see every frame (150 of 150 in a five-second export, not 145) (ESCSUITE-494).
- ESCAPEARTIST: the export dialog's YouTube chapter list makes one line for markers in the same second (keeping the first one's label), so its times always go up and YouTube accepts it, and a marker label that starts with a time, such as "2:30 recap", is written after a dash ("0:15 - 2:30 recap") so YouTube does not read it as the chapter's time (ESCSUITE-496).
- ESCAPEARTIST: shortcut hints show ⌘ on a Mac or an iPad instead of "Ctrl", in the keyboard shortcuts sheet, the File menu, the toolbar and header tooltips and the undo notes (Go to Previous Marker shows ⌃M, as ⌘M minimises the window), and screen readers hear the key spelled out as "Command" or "Control"; other systems still show Ctrl (ESCSUITE-491).
- ESCAPECRAFT: recordings made in Firefox now play back in their true colours: Firefox's encoder converts their pixels with the BT.601 matrix but says BT.709, which ESCAPECRAFT wrote into the file, so every player showed them shifted by up to about 23/255; the recorder now corrects that label to BT.601 (SMPTE 170M) the way ESCAPEARTIST's WebM export does, measured on a Firefox take first (ESCSUITE-503).
- Hosted site: an address that does not exist is served a "Page not found — ESCAPE Suite" title and its own description, asks search engines not to index it, and no longer names the home page as its canonical address or og:url, so link previews and readers without JavaScript no longer see the home page for a dead link; the running page sets the same head (ESCSUITE-489).
- Tests: ESCAPEARTIST's 103 pure-logic unit test files run in Node instead of a jsdom window, so the unit suite spends a third less time creating test environments and finishes about 18% sooner, with the same tests and the same coverage (ESCSUITE-488).
- Tests: an e2e spec reads the colour field of every VP9 key frame in a real ESCAPEARTIST WebM export and a real ESCAPECRAFT WebCodecs take, and checks it names the matrix the file should carry (BT.709 in Chromium, the corrected BT.601 for an ESCAPEARTIST export in Firefox) and agrees with the file's Colour element, also with the encoder's key frames forced to say "unknown" so Chromium's PR runs catch a broken rewrite (ESCSUITE-485).
- ESCAPEARTIST: exports of a 30 fps WebM (an ESCAPECRAFT recording, say) no longer show the previous frame in place of some frames (every third one at a steady 30 fps): the in-page exporters now seek 1 ms past each frame's start, past WebM's millisecond-rounded frame times, instead of 0.1 ms (ESCSUITE-495).
- ESCAPEARTIST: Remove silences' Minimum gap starts at 0.1 s instead of 0, Remove all waits while a setting does not read, and above 500 pauses the list shows them 500 at a time with a Show more button while the summary gives the count and Remove all still cuts them all, so an hour-long recording stays quick to tune (ESCSUITE-487).
- ESCAPEARTIST: when a clip is moved, trimmed, split or removed while "Transcribe to captions" runs, the finishing notice (and a stopped run's) now says the timeline changed while transcribing and the captions follow it as it was when the run started, instead of reporting plain success; renames, style changes and titles do not trigger it (ESCSUITE-486).
- ESCAPEARTIST: in Chrome and Edge, exporting asks where to save the video and writes it straight to that file as it encodes, and Save writes over the project file you opened or first saved instead of downloading another copy; File > Save Project As... picks a new file (ESCSUITE-470).
- ESCAPEARTIST: Zoom to region: drag a box on the preview (or type it) and a video clip eases in to fill the frame with it at the playhead, holds, and eases back out, written as ordinary keyframes that one undo removes (ESCSUITE-475).
- ESCAPEARTIST: a clip can play from 0.25× to 4× (the inspector's new Speed section): its length on the timeline follows, the clips after it move to match, linked parts change speed with it, and its sound plays pitched with the picture up to 2× and silent above, in the preview, every export and the headless render (ESCSUITE-471).
- ESCAPECRAFT and ESCAPEARTIST: the screen stays on while ESCAPECRAFT records and while ESCAPEARTIST exports (MP4, WebM or GIF) or transcribes, where the browser supports it, and the export window says so; it is given up when the job ends or is cancelled and taken again when the tab is shown after being hidden; the Known limitations page notes that a hidden ESCAPECRAFT tab lets the screen sleep (ESCSUITE-474).
- ESCAPEARTIST: the export dialog has a Chapters row that copies the timeline's markers as a YouTube chapter list, or saves it as a .txt, and warns when YouTube would not accept the list (ESCSUITE-472).
- Tests: the on-device transcription regression spec no longer counts WebKit's in-memory read of a clip just added to the timeline (a `blob:` URL, which never reaches the network) as a request made while transcribing, so it stops failing on a slow first attempt (ESCSUITE-481).
- Tests: a regression spec opens Remove silences on an imported clip, changes the threshold and minimum gap, cancels and reopens it, and checks the fields read the defaults beside the pause the defaults find, in Chromium, Firefox and WebKit (ESCSUITE-480).
- ESCAPECRAFT: Delete in the recordings list asks first, naming the recording and, for a take recorded as several files, saying how many go; Cancel and Escape keep it (ESCSUITE-483).
- Tests: a regression spec exports a WebM of a timeline cut into 120 short pieces of a frame-numbered source and checks that every exported frame, each cut's first included, is the source frame the timeline puts there, so an export that writes the frame from before a seek fails in Chromium again (ESCSUITE-479).
- ESCAPEARTIST: Remove silences and Split keep a clip's Transition Out on the piece at its real end only, so a fade or wipe no longer plays at every cut (ESCSUITE-482).
- ESCAPEARTIST: stopping a transcription while it listens, or the speech recogniser failing part-way, keeps the captions heard so far on the Captions track (one Ctrl+Z takes them off) and says how many were added and where it stopped, instead of throwing them all away (ESCSUITE-484).
- ESCAPECRAFT: a recording is kept on your device while it records, so one whose tab closed or crashed, or that ended in an error, is offered back for recovery the next time ESCAPECRAFT opens. Where the browser cannot keep it, a notice says the recording is in memory only (ESCSUITE-466).
- ESCAPEARTIST: Translate captions turns the captions into a second caption track in another language with the browser's on-device translation (Chrome on a computer), keeping their timing; the two languages stack on screen, show and export on their own, and each gets its own caption file (ESCSUITE-473).
- Hosted site: ESCAPEPLAN, ESCAPECRAFT and ESCAPEARTIST work offline after the first visit, each app on its own, in browsers with service workers; Chromium offers to install each one, and a short "Updated" note shows when a new version has been saved. Recordings and projects are stored as before (ESCSUITE-469).
- CI: a pull request's new or changed end-to-end tests now also run in Firefox and WebKit before it can merge, and a Playwright update runs the accessibility checks in both, so a test that only fails in those browsers is caught on the pull request instead of in the next nightly run on main (ESCSUITE-478).
- ESCAPECRAFT and ESCAPEARTIST: after the first saved recording, import or project save in a visit, both apps ask the browser to keep their stored recordings and media, and say whether it agreed (under the recordings in ESCAPECRAFT, in the media library's storage bar in ESCAPEARTIST); the Known limitations page explains Safari's seven-day clean-up of stored data (ESCSUITE-468).
- Hosted site: sitemap.xml is now generated from the site's routes at build time, so new pages are always listed; a hub page that changed recently also carries the date of that change (ESCSUITE-457).
- ESCAPEARTIST: the Remove silences dialog starts every opening from its default settings on its own, rather than relying on the editor to close it fully, so values typed in a cancelled session can never show beside pauses found with the defaults (ESCSUITE-463).
- ESCAPEARTIST: a transcription that fails or is stopped the moment it starts no longer keeps updating its progress afterwards (ESCSUITE-461).
- ESCAPEARTIST: Play on a pause in Remove silences now plays that pause even with loop playback on, instead of jumping to the start of the timeline or to the in point, and stops at the end of the timeline rather than past it (ESCSUITE-462).
- Tests: the hub footer's Support & sponsorship link and its Bonham Technologies link are now checked to point at bonham.tech directly (ESCSUITE-460).
- ESCAPEARTIST: Delete track, Delete clip, New Project and the media library's Remove, Clear Unused and Clear All ask in the editor's own dialog, so they work in a page that embeds the editor in a frame sandboxed without pop-ups, where they used to do nothing (ESCSUITE-448).
- Hosted site: the Privacy, Terms and Known limitations pages are served with their own title, description and canonical address instead of the home page's, so search engines no longer see them as copies of the home page; the home page, ESCAPECRAFT and ESCAPEARTIST have shorter titles and descriptions that show in full in search results (ESCSUITE-458).
- Tests: journey 01 records, without failing, each time an export has to reload a video that stopped completing seeks, and the CI and nightly e2e summaries and their e2e-flaky artifacts list those tests (ESCSUITE-450).
- ESCAPEARTIST: Remove silences says "Ctrl+Z puts it back" for a single pause, warns when the cuts would remove 90 % or more of a clip, and names a locked linked track as soon as it opens, with Remove all disabled (ESCSUITE-449).
- Hosted site: ESCAPECRAFT and ESCAPEARTIST pages now describe themselves to search engines as free web apps (ESCSUITE-456).
- Hosted site and docs: security, privacy, legal and support contacts now go to support@bonham.tech at Bonham Technologies in place of escapesuite.io addresses, and the site serves `/.well-known/security.txt` (BORG-91).
- Hosted site: the Content-Security-Policy no longer allows Vercel's preview-toolbar hosts, and every page now explicitly asks browsers to use HTTPS only, for the site's host and any name under it (ESCSUITE-459).
- ESCAPEPLAN: the Known limitations page now lists the browser limits of Transcribe to captions and Float controls (ESCSUITE-445).
- ESCAPECRAFT, ESCAPEPLAN: Recording Tips explain Float controls where the browser supports them, and the home page lists Remove silences and captions for ESCAPEARTIST (ESCSUITE-446).
- Tests: the MP4 export parity checks wait for each sought frame to be shown before reading it, so a slow machine no longer makes them compare the frame from before the seek (ESCSUITE-437).
- ESCAPEARTIST: Transcribe to captions has a language list beside its button, starting on the browser's language and remembered, so a recording in another language can be transcribed; the language-pack notice names the language (ESCSUITE-444).
- ESCAPECRAFT: the Float controls window shows the 3-2-1 countdown in place of the timer, announces the take's state to screen readers, and prints why Record is unavailable (ESCSUITE-440).
- ESCAPEARTIST: each pause in Remove silences has Go to and Play, so you can hear a pause, with a second either side, before deciding to keep or cut it (ESCSUITE-443).
- ESCAPEARTIST: Keep in Remove silences moves keyboard focus to the next pause (or the previous one, or Cancel) instead of dropping it to the page (ESCSUITE-441).
- ESCAPEARTIST: transcribing again asks whether to replace the existing captions or add to them, instead of stacking a second copy of every caption (ESCSUITE-442).
- Tests: on-device transcription and the repair of WebM seek indexes are tested on more of their edge cases, and the shared package's branch-coverage floor rises to 93% (ESCSUITE-439).
- ESCAPEARTIST: exports no longer sometimes repeat a frame after a cut or trim; WebM and GIF exports, and MP4 exports in Safari, wait for each video frame to be shown before drawing it (ESCSUITE-454).
- ESCAPEPLAN: a link to a page that doesn't exist shows a "Page not found" page, with links home, to ESCAPECRAFT and to ESCAPEARTIST, and the hosted site answers it with a real 404 instead of the home page (ESCSUITE-455).
- Tests: the test tooling is updated to Playwright 1.65, Vitest 5.1 and jsdom 31, with a workaround for a Firefox 159 crash that stopped the cross-browser accessibility checks from running.
- ESCAPEARTIST: Remove silences says how many clips on other tracks and markers it will leave where they are, before the cut and in the message after it.
- ESCAPEARTIST: Remove silences can move everything after each cut (on by default), so overlays, captions, markers and in/out points stay in step with the take; one undo puts it all back.
- Repository: the secret scanner no longer reports a test marker word in the analytics privacy test as a leaked key.
- Releases: each offline build and the headless render kit now ship with an SPDX SBOM (`.spdx.json`) listing the open-source packages inside them, and an attestation tying it to the build. [Verify your download](docs/VERIFY.md) shows how to check it.
- ESCAPEPLAN: the Privacy Policy now lists exactly what the hosted site's analytics records, including the approximate city Vercel works out from your IP address, which Vercel says it does not store.
- ESCAPEARTIST: Remove silences no longer listens to muted or hidden tracks, which the export leaves out, so their sound no longer hides a pause; they are still cut in step with the take.
- ESCAPEARTIST: transcribing to captions shows how much of the sound is prepared, and no longer gets stuck after the sound has played when the browser's speech recognition does not finish.
- ESCAPEARTIST: in the light theme, Remove silences' "Nothing was cut" message and the red border around a setting that is out of range are a darker red, so they are easier to read and to spot.
- ESCAPEARTIST: transcribing to captions uses far less memory (about 230 MB for an hour of timeline), and a timeline over 3 hours is turned down at once with a message that names the limit and suggests a section.
- ESCAPEARTIST: starting a new project, opening one, or a host page loading one while a transcription runs now stops it, so the old project's captions are no longer added to the new one.
- ESCAPEARTIST: the media library's Clear All, Clear Unused and Remove buttons are easier to read, at rest and when you point at them, in both themes.
- ESCAPEARTIST: in the light theme, the warning that browser storage is nearly full is a darker orange, so it is easier to read.
- ESCAPEARTIST: in the light theme, progress bars and slider handles are a darker blue, so they stand out from their tracks.
