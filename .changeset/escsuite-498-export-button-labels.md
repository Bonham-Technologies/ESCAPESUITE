In Chrome and Edge, where exporting asks where to save the file, the export dialog's buttons now read "Export WebM…", "Export MP4…" and "Export GIF…" instead of "Download …", and screen readers announce the same words. Browsers that download the export, such as Firefox and Safari, still show "Download WebM", "Download MP4" and "Download GIF".
