On a Mac (or an iPad with a keyboard), ESCAPEARTIST's shortcut hints now show the Command key, ⌘, instead of "Ctrl": the keyboard shortcuts sheet, the File menu, the Undo, Redo, Save, Export and Duplicate tooltips, and the "⌘Z puts them back" notes. Go to Previous Marker shows Control, ⌃M, on a Mac, since ⌘M minimises the window there. Other systems still show Ctrl. Screen readers hear the key spelled out, "Command" or "Control". The shortcuts themselves work as before, with either key.
