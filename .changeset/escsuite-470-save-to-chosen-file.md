In Chrome and Edge, ESCAPEARTIST now asks where to save an export and writes the video straight to that file while it encodes, so a long export no longer has to fit in the browser's own storage before you get it. Cancelling, or a full disk, leaves no half-written file, and a disk that fills up stops the export and says so. Save now writes over the project file you opened or first saved instead of putting another copy in Downloads, and File > Save Project As... saves to a new file. Firefox and Safari download exports and projects as before.
