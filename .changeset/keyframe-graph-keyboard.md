The keyframe graph is now fully keyboard-operable: Tab into it, move between keyframes with the arrow keys, nudge a keyframe's time and value, add one at the playhead with Enter, and delete with Delete. Screen readers announce each keyframe's time, value and easing. Fixes a bug (ESCSUITE-49) where pressing Delete with a keyframe selected deleted the whole clip.
