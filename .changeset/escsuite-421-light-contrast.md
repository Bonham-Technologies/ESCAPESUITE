In the light theme, the quieter grey text is now a darker grey so it is easier to read: the toolbar's group names, the "Media Library" and "Inspector" headings, the clip details in the inspector, the file details in the media library, the zoom level and the export dialog's options and notes. The message in the empty preview is a lighter grey, so it stands out on its dark box. The outline around a text box or menu item you are typing in or moving through with the keyboard is a darker blue, so it is easier to see. The Export button in the header now has dark lettering on its blue background in both themes, which is much easier to read, also when you point at it. The dark theme otherwise looks the same as before.
