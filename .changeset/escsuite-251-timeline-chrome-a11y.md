Track names can be renamed from the keyboard, markers can be removed with Delete, and the ruler's time labels follow the zoom — tenths of a second when zoomed in, every ten seconds when zoomed out.

A track's name is now a button that Tab reaches and Enter or Space opens for editing (a click or a double-click still does), and each marker flag on the ruler is a focusable button with a spoken name that Delete or Backspace removes. The ruler used to label every five seconds at every zoom; it now picks its tick spacing and label spacing from the zoom, so a frame-level view reads in tenths and a long project does not crowd its ticks.
