The YouTube chapter list in the export dialog now makes one line for markers that fall in the same second, keeping the first marker's label, so the times always go up and YouTube accepts the list. A marker label that starts with a time, such as "2:30 recap", is now written after a dash ("0:15 - 2:30 recap") so YouTube does not mistake it for the chapter's time.
