ESCAPEARTIST can translate your captions on this device. In Chrome on a computer, a Translate captions button beside Transcribe to captions turns the captions into a second caption track in the language you pick, with exactly the same timing, in one undo step. If the browser needs to download a translation model first, it asks before anything is downloaded. Both languages can be shown, hidden and burned in on their own; when both show they are stacked, the original above the translation. The export dialog offers a caption file for each language, named with it (for example Talk.en.vtt and Talk.es.vtt). Transcribed captions now remember their language. The Known limitations page explains where translation is offered, what the browser downloads, and that it works offline only when the model is already installed.
