# Security Policy

## Supported Versions

Only the latest release of ESCAPECRAFT receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| < Latest | :x:               |

## Reporting a Vulnerability

We take security vulnerabilities seriously. If you discover a security issue, please report it responsibly.

### How to Report

**Create a security issue in Jira:**

1. Go to the [ESCSUITE Jira project](https://bonham.atlassian.net/jira/software/projects/ESCSUITE/summary)
2. Create a new issue with type "Bug" and label "security"
3. Mark the issue as confidential if it contains sensitive details

### What to Include

- Description of the vulnerability
- Steps to reproduce the issue
- Potential impact
- Any suggested fixes (optional)

### What to Expect

- **Acknowledgment**: We will acknowledge receipt within 48 hours
- **Initial Assessment**: We will provide an initial assessment within 7 days
- **Resolution Timeline**: Critical vulnerabilities will be prioritized; fixes typically released within 30 days
- **Disclosure**: We will coordinate with you on public disclosure timing

### Scope

This security policy applies to:
- The ESCAPECRAFT application code
- Build and deployment configurations
- Dependencies (we will work with upstream maintainers as needed)

### Out of Scope

- Vulnerabilities in third-party services
- Social engineering attacks
- Physical security issues

## Security Best Practices

When using ESCAPECRAFT:
- Keep your browser updated to the latest version
- Only grant screen/camera/microphone permissions to trusted pages
- Be cautious about where you deploy the recorder

Thank you for helping keep ESCAPECRAFT secure.
