# ESCAPEARTIST Quickstart Guide

Get started editing videos in your browser in just a few minutes.

## Requirements

- **Browser**: Chrome or Edge (recommended for full export support)
- **No installation required** - runs entirely in your browser

## Getting Started

### 1. Import Your Media

Drag and drop files directly into the editor, or click the upload area:

- **Videos**: MP4, WebM, MOV, and other browser-supported formats
- **Images**: PNG, JPG, GIF, WebP (default 5-second duration)
- **Audio**: MP3, WAV, OGG for music or voiceover

Your media is stored locally in your browser - nothing is uploaded to any server.

### 2. Add Clips to the Timeline

- Click a media item in the library to add it to the timeline
- Or drag media directly onto a track
- **New in v1.1**: Clips automatically create a new track if none is selected

### 3. Arrange Your Clips

- **Drag** clips left/right to reposition them
- **Drag handles** on clip edges to trim
- **Split** clips at the playhead position
- Use multiple tracks to layer content

### 4. Adjust Track Audio

Each track has independent audio controls:

| Control | Function |
|---------|----------|
| Speaker icon | Mute/unmute the track |
| Volume slider | Adjust level (0-100%) |

All unmuted tracks play together - the browser mixes them automatically.

### 5. Apply Effects

Select a clip to access the inspector panel:

- **Transform**: Position, scale, rotation, opacity
- **Blend Mode**: How the clip combines with layers below
- **Animation**: Entrance and exit effects
- **Blur**: Apply blur effect to the clip

### 6. Add Overlays

Click the overlay buttons to add:

| Overlay | Use Case |
|---------|----------|
| **Text** | Titles, captions, watermarks |
| **Rectangle** | Highlights, backgrounds |
| **Ellipse** | Circular highlights |
| **Arrow** | Point to elements |
| **Blur** | Privacy blur, focus effects |

**Tip**: Use the "No Fill" button to create outline-only shapes.

### 7. Preview Your Edit

- Press **Space** to play/pause
- Click the timeline to scrub
- Use **arrow keys** to step frame-by-frame

### 8. Export

1. Click the **Export** button
2. Choose format:
   - **WebM** (VP9) - Works everywhere
   - **MP4** (H.264) - Chrome/Edge only
3. Select quality and resolution
4. Click Export and wait for processing
5. Download your video

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `Space` | Play/Pause |
| `←` / `→` | Step 1 second |
| `Home` / `End` | Jump to start/end |
| `Delete` | Delete selected clip |
| `Ctrl+Z` | Undo |
| `Ctrl+Shift+Z` | Redo |
| `Ctrl+S` | Save project |
| `Ctrl+E` | Export |

## Tips for Best Results

### Performance
- Close other browser tabs when exporting
- Use 720p export for faster processing
- Shorter clips export faster

### Audio
- Use the volume slider for background music (try 30-50%)
- Keep dialogue tracks at 100%
- Mute tracks you don't need

### Blur Overlay
- Great for hiding sensitive information
- Position and resize to cover the area
- Rotation affects only the blur shape, not the content

### Saving Work
- Projects auto-save to your browser session
- Use **Save Project** for a downloadable backup
- Projects include all media (can be large files)

## Troubleshooting

### Black preview screen
- Try clicking the timeline to refresh
- Check that clips are on visible tracks (eye icon)

### No audio during playback
- Check that tracks aren't muted (speaker icon)
- Ensure volume slider isn't at 0%
- Some browsers require a click before playing audio

### Export fails
- MP4 requires Chrome or Edge
- Try WebM format instead
- Check browser console for errors

### Large file sizes
- Use lower quality preset
- Use 720p or 480p resolution
- Trim unnecessary footage
